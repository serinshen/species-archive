晨间物种卡

Morning species cards · China wildlife archive

每天一张中国野生种小卡：中文名、英文名、拉丁名、大类，以及六节小知识（栖息地区、生境、外形、食物、育幼、习性），照片可直接嵌入浏览。

图库

如何追加新的一天： 把照片放进 images/，再在 js/cards-data.js 与 data/cards.json 顶部追加一条（最新在前）；小知识用六节 { label, text }（见 FORMAT-6-SECTIONS.md）。刷新即可。也可托管到 GitHub Pages / Netlify。
